## Vivo Qcom机型thermal-engine控制

```
场景（开机 / 进游戏 / 切模式）
        │  写 /proc/pem/thml_key_type = N
        ▼
   thermal-engine-v2
        │  读 N → 加载 thermal_N.conf
        │  读 tz_shell 温度 → 在该组里选档
        ▼
 cooling_device(gpu).cur_state
        ▼
 kgsl thermal_pwrlevel → max_clock_mhz
```

四个角色，各管一段：

| 角色 | 干什么 |
|---|---|
| vperf / GameWatch | 只负责**选组**：把 N 写进 `/proc/pem/thml_key_type` |
| `thermal-engine-v2` | 唯一**执行者**：读组号、读温度、写 cooling device |
| `/data/vendor/thermal/thermal_N.conf` | 每组的具体档位表（温度→频率） |
| `thermal_data_summary.conf` | 引擎把当前组**展开后的快照**，只写不读，给上层看 |

所以：**组号看 `key_type`，降多少看 `tz_shell`，最终都写在 `cooling_device36` 上。** `VivoThermalManagerService` 是旁路，只做热状态分级播报，不参与限频。
